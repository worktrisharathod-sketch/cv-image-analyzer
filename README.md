# Computer Vision Image Analyzer

## Overview

Computer Vision Image Analyzer is a Python-based computer vision application
that analyzes a user-provided image using OpenCV.

The system performs multiple analysis operations and produces both processed
images and a structured text report.

## Features

- Image input and validation
- Face detection using Haar Cascade
- Image dimension and channel analysis
- Average brightness calculation
- Image sharpness assessment
- Canny edge detection
- Processed image generation
- Automated analysis report
- Command-line image input
- Error handling
- Automated tests

## Technologies Used

- Python
- OpenCV
- NumPy
- Pytest
